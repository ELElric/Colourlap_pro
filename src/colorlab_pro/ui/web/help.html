1. Overview

ColorLab Pro is a professional color science tool for LED, Quantum Dot (QD), and Color Filter (CF) display analysis. It provides spectral measurement, color gamut calculation, white point optimization, and thickness optimization capabilities based on CIE standards.

The application uses the CIE 1931 2° Standard Observer as the default color matching function, with D65 as the default reference illuminant. All chromaticity calculations follow international CIE standards.

Core dependencies: colour-science (CIE colorimetry), shapely (gamut geometry), scipy (optimization), numpy (numerical computation).

2. Quick Start Guide

Typical Workflow

  • Step 1: Go to Spectrum Library (Alt+1), import your LED/QD/CF spectral data files.
  • Step 2: Go to Gamut Calculator (Alt+2), select R/G/B spectra and CF materials, adjust thickness, then click "Calculate Gamut".
  • Step 3: (Optional) Click "Send to White Point" to forward RGB primaries to the White Point Calculator.
  • Step 4: (Optional) Go to Thickness Optimizer (Alt+4), run grid search to find optimal CF thicknesses.
  • Step 5: Save results to History or export a report.

Navigation

Use the left sidebar or Alt+1–Alt+6 to switch between pages. The View menu also provides navigation. Theme can be toggled via the Theme menu or the sidebar footer button.

4. Gamut Calculator

Calculates device color gamut from RGB emission spectra + Color Filter (CF) transmittance + CF thickness, and compares against standard gamuts.

Two Modes

  • RGB + Color Filter: Select R/G/B emission spectra and their corresponding CF materials. Each channel's filtered spectrum = emission × Tthickness.
  • White + Color Filter: Select a single white light spectrum; the same white spectrum passes through R/G/B CFs separately.

Thickness & Lambert-Beer Law

The CF thickness applies the Lambert-Beer law to modulate transmittance:

T(λ, d) = T₀(λ)d   →   S_filtered(λ) = S_emission(λ) × T₀(λ)d

where d is the CF thickness in μm, and T₀(λ) is the normalized CF transmittance (0–1). A thickness of 0 means no filtering (passes through unchanged).

CCT (K)Correlated Color Temperature of the white point (Hernandez 1999)

Supported Standards

sRGB, NTSC, DCI-P3, Adobe RGB, BT2020 — each with CIE 1931 xy and CIE 1976 u'v' results.

Tip: Adjusting CF thickness triggers automatic recalculation (500ms debounce). Use the "Send to White Point" button to forward RGB primaries to the White Point page.

5. White Point Calculator

Computes the white point from RGB primaries and mixing ratios, or reverse-solves RGB ratios for a target white point.

Forward Mode (RGB → White)

Enter R/G/B chromaticity coordinates (xy) and mixing ratios. The white point xy is computed as:

XYZ_mix = w_R × XYZ_R + w_G × XYZ_G + w_B × XYZ_B   →   xy_white = XYZ_mix normalized

Reverse Mode (White → Ratio)

Enter R/G/B xy and target white xy. The optimal non-negative mixing ratios are solved using Non-Negative Least Squares (NNLS):

minimize ‖A·w − b‖₂   subject to   w ≥ 0

where A is the 3×3 matrix of XYZ columns and b is the target XYZ (with Y=1).

Results

Displays the white point xy, u'v', CCT, and gamut coverage/match against sRGB/NTSC/DCI-P3/BT2020 in both CIE 1931 and 1976 spaces.

6. Thickness Optimizer

Three optimization modes to find optimal CF thicknesses, CF material combinations, or emission spectra parameters.

Filter 1: CF Thickness Grid Search

Performs an exhaustive grid search over R/G/B CF thickness ranges. For each thickness combination:

  • Compute filtered spectra via Lambert-Beer law
  • Calculate white point and device gamut
  • Score by white point accuracy (Δxy) and gamut coverage

Results are sorted by (Δxy ascending, coverage descending) and the top 5 are returned.

Steps: default 10 per channel → 10³ = 1000 combinations

Filter 2: CF Material Selection

With fixed thicknesses, enumerates all CF material combinations from the library. Returns the top 10 combinations by coverage/match.

Filter 3: Emission Spectra Optimization

Adjusts R/G/B emission spectra by peak wavelength shift (Δλ) and FWHM scaling factor. For QD channels, blue light leakage is separated and preserved.

Peak shift: λ' = λ + Δλ   |   FWHM scaling: FWHM' = FWHM × factor

FWHM scaling uses a power transform: normalized values raised to the power 1/factor².

Sensitivity Analysis

Scans one channel's thickness while holding others fixed, showing how coverage and white point drift. Supports single-channel or all-channels modes.

Note: Grid search complexity is O(steps³). Emission optimization is O(steps⁶). Use steps ≤ 7 for emission optimization to avoid excessive computation time.

9. Calculation Principles

9.1 XYZ Tristimulus Values

From a spectral power distribution S(λ) and the CIE 1931 2° color matching functions:

X = k × Σ S(λ)·x̄(λ)·Δλ   Y = k × Σ S(λ)·ȳ(λ)·Δλ   Z = k × Σ S(λ)·z̄(λ)·Δλ k = 100 / Σ ȳ(λ)·Δλ (for illuminant E)

9.2 Chromaticity Coordinates

x = X / (X+Y+Z)   y = Y / (X+Y+Z)

9.3 CIE 1976 u'v'

u' = 4x / (−2x + 12y + 3)   v' = 9y / (−2x + 12y + 3)

9.4 Correlated Color Temperature (CCT)

Computed using the Hernandez 1999 approximation (an improvement over McCamy 1992):

CCT ≈ f(x, y) via polynomial approximation

9.5 Gamut Coverage and Match

Gamut triangles are modeled as shapely Polygon objects in xy (or u'v') space:

Coverage = Area(device) / Area(target) × 100% Match = Area(device ∩ target) / Area(target) × 100%

Coverage can exceed 100% if the device gamut is larger than the target. Match is always ≤ 100%.

9.6 Lambert-Beer Law (CF Thickness)

T(λ, d) = T₀(λ)d   →   S_filtered(λ) = S_source(λ) × T₀(λ)d

where d is thickness (μm), T₀ is normalized transmittance (0–1). The absorption coefficient α = −log₁₀(T₀).

9.7 QD Blue Light Leakage Separation

QD spectra contain blue LED leakage. The leakage ratio k is estimated by least-squares:

k = Σ[QD(λ)·B_LED(λ)] / Σ[B_LED(λ)²]   (for λ < cutoff)

QD emission = max(QD_total − k × B_LED, 0). When adjusting QD emission (peak/FWHM), the blue leakage is preserved separately.

9.8 FWHM Measurement and Scaling

FWHM is measured by linear interpolation to find the half-maximum crossing points. Scaling uses a power transform: for a Gaussian peak, raising normalized values to power p scales FWHM by 1/√p.

FWHM' = FWHM × factor   →   p = 1/factor²   →   S'(λ) = peak × (S(λ)/peak)p

9.9 White Point Mixing (NNLS)

Non-negative least squares to find optimal RGB mixing ratios for a target white point:

minimize ‖A·w − b‖₂   subject to   w ≥ 0 A = [XYZ_R | XYZ_G | XYZ_B],   b = target XYZ (Y=1)

11. Important Notes

CF Transmittance Format: The application auto-detects whether CF transmittance is in 0–1 or 0–100% format. If max value > 1.5, it is treated as percentage and divided by 100. Ensure your CF data does not have ambiguous scaling.
QD Blue Leakage: QD spectra typically contain blue LED leakage below ~500nm. When optimizing QD emission (peak/FWHM), the leakage component is separated and preserved. If the B-LED changes, leakage is recalculated using the stored ratio k. Always select the correct B-LED spectrum for QD channels in the emission optimizer.
Wavelength Range: The standard calculation grid is 380–780nm at 1nm resolution (401 points). Spectra outside this range are automatically interpolated. Ensure your spectra cover at least the visible range for accurate results.
Coverage vs Match: Coverage can exceed 100% (device gamut larger than target). Match is always ≤ 100% (intersection area). A high coverage with low match indicates the device gamut is large but misaligned with the target.
CCT Accuracy: CCT is computed via the Hernandez 1999 approximation. For chromaticities far from the Planckian locus (Duv > 0.05), CCT may not be meaningful. Always check Duv alongside CCT.
Computation Time: Grid search with steps=10 takes ~1–2 seconds. Emission optimization with steps=5 evaluates 15,625 combinations and may take 10–30 seconds. Use the Stop button to cancel long-running optimizations.
Best Practice: For accurate results, import spectra with 1nm or 5nm resolution. Avoid spectra with fewer than 50 data points. Always verify the spectrum category (LED/QD/CF/W) during import, as this affects how the spectrum is processed.

1. 概述

ColorLab Pro 是一款专业的颜色科学工具，用于 LED、量子点（QD）和彩色滤光片（CF）显示器分析。基于 CIE 国际标准，提供光谱测量、色域计算、白点优化和膜厚优化功能。

应用程序默认使用 CIE 1931 2° 标准观察者作为颜色匹配函数，D65 作为默认参考光源。所有色度计算均遵循 CIE 国际标准。

核心依赖库： colour-science（CIE 色度学）、shapely（色域几何运算）、scipy（优化求解）、numpy（数值计算）。

4. 色域计算器

基于 RGB 发射光谱 + 彩色滤光片（CF）透过率 + CF 厚度，计算设备色域三角形，并与标准色域对比。

两种模式

  • RGB + Color Filter：分别选择 R/G/B 发射光谱及对应的 CF 材料。每个通道的滤光后光谱 = 发射光谱 × T厚度。
  • White + Color Filter：选择一个白光光谱，同一白光分别通过 R/G/B 滤光片。

厚度与朗伯-比尔定律

CF 厚度通过朗伯-比尔定律调制透过率：

T(λ, d) = T₀(λ)d   →   S_滤光后(λ) = S_发射(λ) × T₀(λ)d

其中 d 为 CF 厚度（μm），T₀(λ) 为归一化 CF 透过率（0–1）。厚度为 0 时无滤光效果（原样通过）。

结果说明

提示： 调整 CF 厚度会自动触发重算（500ms 防抖）。点击"Send to White Point"按钮可将 RGB 基色坐标传给白点计算器。

5. 白点计算器

根据 RGB 基色和混合比例计算白点坐标（正向），或反推达到目标白点所需的 RGB 比例（反向）。

正向模式（RGB → 白点）

输入 R/G/B 色度坐标（xy）和混合比例，白点 xy 计算公式：

XYZ_混合 = w_R × XYZ_R + w_G × XYZ_G + w_B × XYZ_B   →   xy_白点 = XYZ_混合归一化

反向模式（白点 → 比例）

输入 R/G/B xy 和目标白点 xy，使用非负最小二乘法（NNLS）求解最优非负混合比例：

最小化 ‖A·w − b‖₂   约束   w ≥ 0

其中 A 为 3×3 的 XYZ 列矩阵，b 为目标 XYZ（Y=1）。

结果说明

显示白点 xy、u'v'、CCT，以及与 sRGB/NTSC/DCI-P3/BT2020 的色域覆盖率和匹配度（CIE 1931 和 1976 空间）。

6. 膜厚优化器

提供三种优化模式：CF 厚度网格搜索、CF 材料组合选择、发射光谱参数优化。

Filter 1：CF 厚度网格搜索

对 R/G/B CF 厚度范围进行穷举网格搜索。对每组厚度组合：

  • 通过朗伯-比尔定律计算滤光后光谱
  • 计算白点和设备色域
  • 按白点精度（Δxy）和色域覆盖率评分

结果按（Δxy 升序，覆盖率降序）排序，返回前 5 个最优结果。

步数：默认每通道 10 步 → 10³ = 1000 种组合

Filter 2：CF 材料选择

在固定厚度下，枚举 CF 库中所有材料组合。返回覆盖率/匹配度前 10 的组合。

Filter 3：发射光谱优化

通过峰值波长平移（Δλ）和 FWHM 缩放因子调整 R/G/B 发射光谱。对于 QD 通道，蓝光泄漏被分离并保留。

峰值平移：λ' = λ + Δλ   |   FWHM 缩放：FWHM' = FWHM × factor

FWHM 缩放采用幂变换：归一化值取 1/factor² 次幂。

灵敏度分析

固定其他通道，扫描某一通道的厚度，展示覆盖率和白点漂移趋势。支持单通道和全通道模式。

注意： 网格搜索复杂度为 O(steps³)。发射光谱优化复杂度为 O(steps⁶)。发射光谱优化建议 steps ≤ 7，以避免计算时间过长。

9. 计算原理

9.1 XYZ 三刺激值

由光谱功率分布 S(λ) 和 CIE 1931 2° 颜色匹配函数计算：

X = k × Σ S(λ)·x̄(λ)·Δλ   Y = k × Σ S(λ)·ȳ(λ)·Δλ   Z = k × Σ S(λ)·z̄(λ)·Δλ k = 100 / Σ ȳ(λ)·Δλ（等能光源 E 时）

9.2 色度坐标

x = X / (X+Y+Z)   y = Y / (X+Y+Z)

9.3 CIE 1976 u'v'

u' = 4x / (−2x + 12y + 3)   v' = 9y / (−2x + 12y + 3)

9.4 相关色温（CCT）

使用 Hernandez 1999 近似法计算（McCamy 1992 的改进版）：

CCT ≈ f(x, y) 多项式近似

9.5 色域覆盖率和匹配度

色域三角形在 xy（或 u'v'）空间中建模为 shapely Polygon 多边形：

覆盖率 = 设备色域面积 / 目标色域面积 × 100% 匹配度 = 交集面积 / 目标色域面积 × 100%

覆盖率可超过 100%（设备色域大于目标时）。匹配度恒 ≤ 100%。

9.6 朗伯-比尔定律（CF 厚度）

T(λ, d) = T₀(λ)d   →   S_滤光后(λ) = S_光源(λ) × T₀(λ)d

其中 d 为厚度（μm），T₀ 为归一化透过率（0–1）。吸收系数 α = −log₁₀(T₀)。

9.7 QD 蓝光泄漏分离

QD 光谱中通常含有蓝光 LED 泄漏。泄漏比 k 通过最小二乘法估计：

k = Σ[QD(λ)·B_LED(λ)] / Σ[B_LED(λ)²]  （λ < 截止波长时）

QD 发射 = max(QD_总 − k × B_LED, 0)。调整 QD 发射（峰值/FWHM）时，蓝光泄漏被分离保留。

9.8 FWHM 测量与缩放

FWHM 通过线性插值找到半高交叉点测量。缩放采用幂变换：对于高斯峰，归一化值取 p 次幂后 FWHM 变为原来的 1/√p。

FWHM' = FWHM × factor   →   p = 1/factor²   →   S'(λ) = peak × (S(λ)/peak)p

9.9 白点混合（NNLS）

使用非负最小二乘法求解达到目标白点的最优 RGB 混合比例：

最小化 ‖A·w − b‖₂   约束   w ≥ 0 A = [XYZ_R | XYZ_G | XYZ_B],   b = 目标 XYZ (Y=1)

11. 注意事项

CF 透过率格式： 应用程序自动检测 CF 透过率是 0–1 还是 0–100% 格式。如果最大值 > 1.5，则视为百分比并除以 100。请确保 CF 数据的缩放方式不会产生歧义。
QD 蓝光泄漏： QD 光谱通常在 500nm 以下含有蓝光 LED 泄漏。在优化 QD 发射（峰值/FWHM）时，泄漏成分会被分离并保留。如果 B-LED 发生变化，将使用存储的泄漏比 k 重新计算泄漏。在发射光谱优化器中，请始终为 QD 通道选择正确的 B-LED 光谱。
波长范围： 标准计算网格为 380–780nm，1nm 分辨率（401 个点）。超出此范围的光谱会自动插值。请确保光谱至少覆盖可见光范围以获得准确结果。
覆盖率 vs 匹配度： 覆盖率可以超过 100%（设备色域大于目标时）。匹配度恒 ≤ 100%（交集面积）。高覆盖率但低匹配度说明设备色域虽大但与目标不对齐。
CCT 精度： CCT 通过 Hernandez 1999 近似法计算。对于远离普朗克轨迹的色度（Duv > 0.05），CCT 可能无意义。请同时检查 Duv 值。
计算时间： 网格搜索 steps=10 约需 1–2 秒。发射光谱优化 steps=5 需评估 15,625 种组合，可能需要 10–30 秒。可使用 Stop 按钮取消长时间运行的优化。
最佳实践： 为获得准确结果，建议导入 1nm 或 5nm 分辨率的光谱。避免使用少于 50 个数据点的光谱。导入时务必核实光谱分类（LED/QD/CF/W），因为分类会影响光谱的处理方式。
